# Kettu Font: Inter + IBM Plex Sans Arabic

A font mod for **Kettu**. It merges **Inter** (English / Latin) and **IBM Plex Sans Arabic** (Arabic) into a single font, so both languages look clean in Discord.

## How to install

In Kettu:

**Fonts → + → Import font** → paste this link:

```
https://github.com/YEMENI-modder/Kettu-Customfontt-Arb-Eng/raw/refs/heads/main/INTER%20%2B%20IBM%20ARB.JSON
```

---

## تعديل خط لـ Kettu

هذا المستودع تعديل خط لـ Kettu، يدمج خط **Inter** للإنجليزي مع **IBM Plex Sans Arabic** للعربي في خط واحد.

### طريقة التثبيت

من Kettu:

**Fonts ← + ← Import font** ثم الصق الرابط أعلاه.

## Files

- `INTER + IBM ARB.JSON` — font definition used by Kettu
- `InterPlexArabic-Bold.ttf` — the merged font
